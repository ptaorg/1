# pdfs/ ディレクトリ

このフォルダには、全国PTA資料館で**直接表示する重要PDF**を配置します。

## 命名規則
`{自治体コード}-{種別}-{連番}.pdf` のように、自治体・種別が判別可能な名前にします。

例:
- `yokohama-application-001.pdf` (横浜市・入会申込書・1)
- `kawasaki-fee-001.pdf` (川崎市・会費徴収関連・1)

## 大量のPDFについて
全件はGoogle Driveに置き、本サイトはリンクで参照します。
GitHub上には**特に重要・象徴的な数本のみ**配置することで、リポジトリの容量を抑えます。
